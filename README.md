# AVYS Ganesha for Android

Download the latest signed APK from [GitHub Releases](https://github.com/avysganesha/Ganesha-Android-Releases/releases/latest).

## Install

1. Open the release page on your Android phone and download the APK under **Assets**.
2. Open the downloaded file. If Android asks, allow your browser or file manager to install apps from this source.
3. Install **AVYS Ganesha** and sign in with your existing website account.

Requires **Android 7.0 or later** and an internet connection. The app connects to [AVYS Ganesha](https://avysganesha.vercel.app) and shares its accounts, records, permissions, and features.

PDF and Excel exports open the Android save dialog. Photo/video and spreadsheet selection use the system picker. App exports are limited to 32 MB; larger exports can be made from the website.

## Updates

Download the new APK and install it over the existing version. Keep the installed app; uninstalling is unnecessary. GitHub Releases does not automatically install updates. Each release includes a SHA-256 checksum and uses the same AVYS signing key.

This repository hosts public Android downloads and installation instructions. Application source and signing credentials are maintained separately. iOS is not included.

Never include passwords, OTPs, donor details, financial records, or other personal information in public issue reports.
